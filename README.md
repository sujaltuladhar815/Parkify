# Parkify 🚗

Parkify is a Smart Parking Management System designed to simplify and automate the parking process. The system uses License Plate Recognition (LPR) to identify vehicles, manage parking slot occupancy, track vehicle entry and exit, and provide users with parking-related services such as reservations and online payments.

The project combines a web-based parking management system with computer vision and AI-based license plate detection to improve parking efficiency and reduce manual work.

## Features

- User registration and authentication
- Vehicle registration and management
- Parking slot booking and availability
- License Plate Recognition using YOLOv8 and OCR
- Online payments with Stripe
- Parking history and reports
- Admin dashboard for managing users, bookings, slots, and payments

## Tech Stack

**Frontend:** HTML, CSS, JavaScript
**Backend:** PHP, Node.js, Express.js
**Database:** MySQL
**AI/ML:** Python, OpenCV, YOLOv8, OCR
**Authentication:** JWT, Google OAuth
**Payment:** Stripe

## Setup

1. Clone the repository:

```bash
git clone https://github.com/sujaltuladhar815/Parkify.git
```

2. Set up the MySQL database using the project database configuration.
3. Install Node.js dependencies:

```bash
npm install
```

4. Install Python dependencies:

```bash
pip install -r requirements.txt
```

5. Create a `.env` file and add the required credentials.
6. Run the project using XAMPP and Node.js.
